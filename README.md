# Godot Platformer

A 2D platformer game built with [Godot](https://godotengine.org/).

## Current Features

* Player movement
* Platforming
* Collectible coins
* Level 1

## Tech Stack

* Godot
* GDScript

## Status

🚧 **In development**

This project is currently a work in progress. More levels, mechanics, enemies, and polish will be added as development continues.
